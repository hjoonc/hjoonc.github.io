## RTOS
Real Time Operating System의 약자

Multi-tasking을 지원하는 OS

<br>

## FreeRTOS
RTOS의 한 종류

비교적 가볍고 다양한 MCU에서 사용할 수 있어서 임베디드 시스템에서 많이 사용됨

<br>

## RTOS 핵심 동작 개념
| 개념              | 설명                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| **Task**          | 프로그램을 **여러 개의 독립적인 작업 단위로 분리하여 실행.** 각 Task에는 **Priority**를 설정할 수 있음.                                         |
| **Priority**      | **Task의 실행 우선순위.** **여러 Task가 동시에 실행 가능한 상태라면 높은 Priority의 Task가 우선**적으로 실행됨.                                 |
| **Delay** | **Task를 일정 시간 동안 실행 대상에서 제외**함. **높은 Priority의 Task가 CPU를 계속 점유하여 낮은 Priority의 Task가 실행되지 않는 것을 방지하기 위해 필요**하며, Delay 동안 다른 Task가 실행될 수 있도록 CPU 실행권을 넘겨줌. |
| **Scheduler** |**Task의 상태와 Priority를 기반으로 실행할 Task를 결정하는 RTOS 내부 기능.** CPU는 실제로 한 순간에는 하나의 명령 흐름만 실행함. 그러므로 Scheduler가 각 Task에 CPU 사용권을 나눠줌.|

<br>

## RTOS Task 간 통신 및 동기화
| 개념              | 설명                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| **Semaphore**     | **공유 자원 접근 제어** 또는 **Task 간 실행 순서/이벤트 동기화**에 사용                                                                 |
| **Mutex**         | 하나의 **공유 자원에 여러 Task가 동시에 접근하는 것을 방지**하기 위한 Lock                                                                  

<br>

## Interrupt / 시간 관련
| 개념              | 설명                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------- |
| **Timer**         | **일정 시간 이후 또는 일정 주기**로 특정 동작을 수행하기 위해 사용.                                                                 |
| **Callback** | 특정 이벤트가 발생했을 때 **미리 등록해 둔 함수를 호출하는 방식.** CAN 수신 완료, Timer 만료 등의 시점에 Callback 함수가 호출될 수 있음. |
| **ISR**           | **하드웨어 Interrupt 발생 시 실행되는 처리 루틴.** 일반적으로 최소한의 처리 후 실제 작업을 Task에 전달함.                                     |
